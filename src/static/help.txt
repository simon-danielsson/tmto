Subcommands:
help -> print help
big -> render as large text

Flags:
-t <int> -> total duration of one work-rest cycle in minutes
-r <int> -> total duration of the rest interval (the work interval is the sum of total - rest)

Example usage:
tmto -t 30 -r 10
tmto big -t 60 -r 20

Controls:
[Ctrl-C] -> quit
[Escape] -> quit
Any key -> pause
